Ecommerce / 2025

LYRA Snacks.

An educational ecommerce demo with a catalog, cart, orders, and administration, built with Next.js and TypeScript.

View sourceView demoEducational demo

Problem & context

LYRA Snacks is an educational demo bringing together an ecommerce application's layers: interface, authentication, catalog, cart, orders, and administration. The repository makes this flow available for examination. The public demo review was limited to the landing page and its access and language links.

My contribution

Full-stack development of an educational demo published in my repository. Public contributor information lists my account; the available code supports work across React components, API routes, services, validation, and tests. This does not establish exclusive authorship of every line or a commercial relationship with the illustrative brand.

Technologies

  • Next.js
  • TypeScript
  • React
  • Tailwind CSS
  • MongoDB
  • NextAuth
  • Jest
  • Cypress
01

From catalog to order

Components and routes implement catalog browsing, a cart, and order creation. The reviewed scope covers orders through an API; a payment integration was not verified.

02

Features by role

The code distinguishes users and administrators in product and order routes. Administration includes filtered, paginated queries and product operations.

03

Access and languages

The implementation includes credentials and Google access when configured, plus Spanish, English, German, and Hebrew dictionaries. No accounts were created or emails sent during the review.

01

API permissions

The order route checks session and role before querying or modifying data. Authorization is enforced on the server, where operations hidden by an interface also need protection.

02

Services and validation

Order operations are separated into services and inputs are validated with Yup schemas. This separation makes data rules and MongoDB access through Mongoose available for review.

03

Tests with a visible scope

The repository includes Jest tests for components, permissions, and templates, plus Cypress tests for authentication pages. Their presence and scope were inspected; no claim is made that the entire suite was run or passed.

Available evidence

  • Orders API

    Session and role checks for order operations.

  • Order services

    Order data access code separated from application routes.

  • Repository tests

    Existing component, permission, and template tests; their results were not executed in this review.

  • Public demo

    Landing page available when reviewed on October 1, 2026. No purchases, registrations, or email sends were performed.

Next steps

  • Run and document the test suites in an environment with the required dependencies and services.
  • Extend tests of the catalog, cart, and order flow using controlled data.
  • Review behavior under simultaneous orders before considering commercial use.

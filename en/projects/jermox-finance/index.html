Personal finance / 2025

JERMOX FINANCE.

A financial interface bringing income, expenses, budgets, and visualizations together in one dashboard.

View sourceView demoTeam project

Problem & context

JERMOX FINANCE is a team project exploring personal finance management in a web application. Its repository documents a dashboard for transactions, budgets, and a Colombian tax estimate. Source review supports this scope; the demo was checked through its public landing page.

My contribution

The README identifies me as a frontend developer on a five-person team. My documented contribution focuses on the interface and its connection to the project's services. The backend technologies belong to the team's application.

Technologies

  • JavaScript
  • Vite
  • Chart.js
  • Node.js
  • Express
  • PostgreSQL
01

A shared view of the month

The dashboard implements income, expense, and balance indicators, category breakdowns, and budget comparisons. The selected period is applied across the view's components.

02

Explore and manage transactions

The interface includes period filters, search, and pagination, plus API clients for creating, editing, and deleting income and expense entries.

03

Additional financial context

The code includes a financial profile, tax summary, PDF report requests, and a conversational assistant. These flows require services and a session; they were not executed during the public demo review.

01

A shared API client

frontend/src/api.js centralizes the base URL, session header, and error handling. This structure concentrates the communication contract used by the interface.

02

Consistent charts and data

frontend/src/dashboard.js applies the selected period to indicators, tables, and charts. The observable technical challenge is keeping query conditions consistent across different representations of transactions.

03

Separate interface and services

The repository separates a Vite and Chart.js frontend from an Express and PostgreSQL backend. The evidence establishes my frontend role; the backend routes and dependencies explain the application's integration.

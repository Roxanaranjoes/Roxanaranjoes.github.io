JERMOX FINANCE.

Una interfaz financiera que reúne ingresos, gastos, presupuestos y visualizaciones en un mismo dashboard.

Ver códigoVer demoProyecto colaborativo

Problema y contexto

JERMOX FINANCE es un proyecto de equipo que propone organizar las finanzas personales en una aplicación web. El repositorio documenta un dashboard de movimientos, presupuesto y una estimación tributaria para Colombia. La revisión del código respalda ese alcance; la demo se comprobó hasta su página pública de entrada.

Mi contribución

El README me identifica como desarrolladora frontend dentro de un equipo de cinco personas. Mi aporte documentado se sitúa en la interfaz y su conexión con los servicios del proyecto. Las tecnologías backend forman parte de la aplicación del equipo.

Tecnologías

  • JavaScript
  • Vite
  • Chart.js
  • Node.js
  • Express
  • PostgreSQL
01

Una lectura conjunta del mes

El dashboard implementa indicadores de ingresos, gastos y balance, una distribución por categoría y comparación frente al presupuesto. El período seleccionado se utiliza en los distintos componentes de la vista.

02

Explorar y gestionar movimientos

La interfaz incluye filtros por período, búsqueda y paginación, además de clientes para crear, editar y eliminar ingresos y gastos mediante la API.

03

Contexto financiero adicional

El código incluye perfil financiero, resumen tributario, solicitudes de reportes PDF y un asistente conversacional. Estos flujos requieren servicios y sesión; no se ejecutaron durante la revisión de la demo pública.

01

Un cliente para la API

frontend/src/api.js centraliza la URL base, la cabecera de sesión y el manejo de errores. Esta estructura concentra el contrato de comunicación que utiliza la interfaz.

02

Coherencia entre gráficas y datos

frontend/src/dashboard.js aplica el período seleccionado a indicadores, tablas y gráficas. La dificultad técnica observable es mantener las mismas condiciones de consulta en distintas representaciones de los movimientos.

03

Interfaz y servicios separados

El repositorio separa el frontend con Vite y Chart.js del backend con Express y PostgreSQL. La evidencia acredita mi rol frontend; las rutas y dependencias backend permiten entender la integración del conjunto.

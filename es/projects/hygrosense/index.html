HygroSense.

Dashboard de humedad y temperatura con integración de Arduino Cloud, resúmenes del ambiente y un chat con OpenAI.

Leer el contexto y mi contribución completa

Problema y contexto

HygroSense explora cómo presentar lecturas de humedad y temperatura junto con una explicación del ambiente. El código conecta Arduino Cloud con un dashboard y servicios OpenAI mediante rutas de servidor. La interfaz pública estaba disponible durante la revisión; las lecturas del sensor y las respuestas de IA no se confirmaron en funcionamiento.

Mi contribución

Los commits públicos de mi cuenta documentan desarrollo del dashboard, integración con servicios y mejoras de experiencia. Entre los cambios observables están el diseño responsive y la memoria reciente del chat. La implementación utiliza servicios OpenAI y no implica entrenamiento de un modelo propio.

Tecnologías

  • Next.js
  • TypeScript
  • React
  • Tailwind CSS
  • Arduino Cloud REST API
  • OAuth2
  • OpenAI SDK
01

Lecturas y contexto en una vista

El dashboard incluye estados para humedad, temperatura y un resumen narrativo del ambiente. La interfaz prevé actualizaciones periódicas y presenta valores de espera mientras no hay datos.

02

Conversación con contexto reciente

La ruta de chat transmite a OpenAI hasta seis mensajes recientes. El alcance observable es una integración conversacional apoyada en servicios externos.

03

Comunicar espera y errores

La interfaz incluye estados de carga, mensajes de error y ajustes responsive. La coordinación de consultas al sensor y respuestas de IA se refleja en estos estados del producto.

01

Integraciones en el servidor

Las credenciales y las solicitudes a servicios externos se gestionan mediante rutas y módulos del servidor. La interfaz consume estos endpoints para reunir lecturas y resumen del ambiente.

02

Vigencia del token de Arduino

lib/arduino.ts implementa OAuth2 y reutiliza el token hasta su vencimiento. La ruta overview renueva el token y reintenta la consulta tras una respuesta 401 de Arduino Cloud.

03

Coordinación de datos externos

El código consulta ambas propiedades en paralelo y valida valores numéricos antes de utilizarlos. El dashboard programa consultas cada diez segundos; esa frecuencia describe la implementación, sin acreditar lecturas activas durante la revisión.
